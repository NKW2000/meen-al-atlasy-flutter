# قائمة الاختبار اليدوي — قبل أي نشر

هاي بوابة القبول النهائية. المحرّك والشبكة (على loopback) والمتحكّمات
والشاشات مغطّيين باختبارات (`flutter test`، ~٣٠٠ اختبار)، بس البثّ على
واي فاي حقيقي وسلوك الأجهزة **ما بينختبر إلا على أجهزة حقيقية**.

**الأجهزة المطلوبة:** جهاز للمضيف + جهاز لكل لاعب (٥ أجهزة عالأقل حتى
تنجرب دورة الفريق كاملة)، أندرويد ٨٫٠ أو أحدث، الكل على نفس الواي فاي أو
على نقطة اتصال المضيف. ما في صلاحيات بتنطلب.

## التركيب

```bash
flutter build apk --release --flavor game
adb install -r build/app/outputs/flutter-apk/app-game-release.apk   # على كل جهاز
```

- [ ] تركيب نسخة جديدة **فوق** القديمة بيشتغل بدون حذف (نفس مفتاح التوقيع)
- [ ] الديمو بيتركّب جنب اللعبة كتطبيق تاني «مين الأطليسي — ديمو» وبيفتح على المعرض

## الشبكة والغرف

- [ ] المضيف يضغط «بدء البث» ← بيبيّن عنوان الواي فاي تبعه والنقطة الخضرا بتنبض
- [ ] بدون واي فاي: شارة «افتح الواي فاي أو نقطة الاتصال» وزر البث معطّل
- [ ] الغرفة بتبيّن عند اللاعب خلال ~ثانيتين على نفس الواي فاي
- [ ] الغرفة بتبيّن عند اللاعب على **نقطة اتصال** المضيف (بيانات الخلوي شغّالة وطافية)
- [ ] الغرفة بتبيّن **مرة وحدة** حتى لو المضيف عنده واي فاي ونقطة اتصال مع بعض
- [ ] المضيف يوقف (يطلع للرئيسية) ← الغرفة بتختفي عند اللاعب خلال ~٦ ثواني
- [ ] المضيف يعيد الاستضافة ← الغرفة بتبيّن مرة وحدة (مش نسختين)
- [ ] فشل الاتصال بغرفة (المضيف طفّى الواي فاي لحظتها) ← رسالة وردية والبحث بيرجع لحاله بدون ما يطلع اللاعب من الشاشة

## إعدادات المضيف

- [ ] «استضافة لعبة» بتفوت على الإعدادات قبل اللوبي
- [ ] تسمية الفريقين والغرفة بتنكتب بكيبورد الجهاز وبتنحفظ بعد إعادة التشغيل
- [ ] الأسماء الجديدة بتبيّن عند اللاعبين باللوبي وبكل الشاشات **بدون** ما يطلع المضيف ويرجع
- [ ] تغيير ثواني المواجهة بينعكس على عدّاد المواجهة، وثواني الجواب على عدّاد الجواب
- [ ] تغيير عدد الأخطاء بينعكس على عدد الـ ✕ وعلى فتح السرقة
- [ ] الإعدادات من الشاشة الرئيسية فيها استيراد البنك وبس

## اللوبي

- [ ] شاشة الانضمام بتفتح كيبورد الجهاز على طول، والخانة والزر بيضلوا فوقه
- [ ] بعد الاتصال اللاعب بيشوف الفريقين بأسماء المضيف ورقمه بالفريق
- [ ] الدوس على الفريق التاني بينقل اللاعب، وبيبيّن عند المضيف فوراً
- [ ] «بدّل ⇄» عند المضيف بينقل اللاعب وبيعيد ترقيم الفريقين
- [ ] زر «ابدأ اللعبة» ما بينفتح إلا لما يكون بكل فريق لاعب متصل
- [ ] بعد ما تبلّش اللعبة ما بيضل حدا يقدر يبدّل فريقه
- [ ] لوبي المضيف بالطولي: الكرتين والأزرار كلهم ظاهرين (ما في مستطيل رمادي)

## الافتتاحية

- [ ] «الجولة الأولى» + لافتة المضاعف، وبعدها «استعدوا» بأسماء لاعبَي المنصة — عند المضيف وكل اللاعبين
- [ ] الدوس عليها ما بيتخطّاها ولا بيوصل لشي تحتها
- [ ] «بدّل السؤال» ما بيعيد الافتتاحية؛ الجولة الجاية بتعيدها

## المواجهة

- [ ] بأول جولة: لاعب المنصة بكل فريق بس اللي شاشته زر ذهبي بينبض
- [ ] ضغطة الزر بتسمّع صوت وبتهزّ الجهاز فوراً، وبتقفل الزر عالتاني (الفرق محسوس)
- [ ] عدّاد المواجهة بيعدّ من لحظة فتح الزر وبيجمد عند الضغطة
- [ ] خلص العدّاد بدون ضغطة ← عند المضيف «بدّل السؤال ⟳» والزر لسا شغّال عند اللاعبين
- [ ] كشف الجواب رقم ١ ← «العب أو تمرير» عند الفائز فوراً
- [ ] كشف جواب أقل ← الدور بينتقل للاعب المنصة التاني بوقت جواب كامل، والأعلى بياخد اللوح
- [ ] غلط من الاتنين ← الزر بيرجع يفتح لنفس السؤال وبيبيّن «بدّل السؤال»
- [ ] بالجولة الجاية: لاعب المنصة بيتبدّل للي بعده

## العب أو تمرير

- [ ] بابين بينزلقوا، والشريط الذهبي بينفضى بسلاسة (بدون نطّات) وبيتوافق مع عدّاد المضيف
- [ ] الاختيار بيوصل للمضيف، وبعده البابين بينفتحوا وما بينعاد الاختيار
- [ ] ما قرر بالوقت ← بيلعب

## اللعب والسرقة

- [ ] الدور بينتقل **للاعب اللي بعد** لاعب المنصة، وبلوك الدور عند اللاعبين بيقول «دور فلان» برقمه
- [ ] الخانات المخفية عند اللاعب أرقام بس؛ المضيف يدوس على خانة ← بتنقلب عند الكل بنفس الحجم
- [ ] لوح اللاعب ما بيتلوّن وما بياخد كبسة — وعدّاد الجواب ما بيوقف
- [ ] خلص وقت الجواب بدون حكم ← بينحسب غلط (X) عند الكل
- [ ] «غلط» بيزيد X وبيبيّن X كبير عند الكل، وكل رقم X إلو صوته
- [ ] ثلاث X بتنقل الفرصة للاعب المنصة عند الفريق التاني
- [ ] سرقة ناجحة: صوت الكشف، وكل نقاط الجولة للفريق التاني
- [ ] سرقة فاشلة: صوت الغلط (مش صوت X ولا الفوز)، والنقاط للفريق الأول
- [ ] نهاية الجولة: «اكشف الباقي» بيقلب الخانات وحدة ورا التانية، وبعدها «الجولة الجاية»
- [ ] مضاعف الجولة (×٢ و×٣) بينعكس على النقاط المضافة بلوحة النتيجة

## النتيجة والنهاية

- [ ] لوحة النتيجة عند الكل: الأرقام بتعدّ، المتقدّم بيضوي، ولافتة «… بالمقدمة»
- [ ] «النتيجة النهائية» بالجولة الأخيرة ← شاشة النهاية عند الكل بـ«فاز …» وألعاب نارية؛ التعادل «تعادل!»
- [ ] «رجوع للوبي» بيرجّع نفس اللاعبين للوبي بنقاط صفر؛ «الرئيسية» بتسكّر الغرفة عند الكل

## الانقطاع والرجوع

- [ ] فصل جهاز لاعب أثناء اللعب (طفّي الواي فاي) ← بينعلّم «منقطع» عند المضيف بدون ما يطيح التطبيق
- [ ] الدور بيتخطّى اللاعب المنقطع وما بيعلق عليه
- [ ] جهاز اللاعب المنقطع بيعرض «انقطعت عن اللعبة» مع «ارجع لللعبة»
- [ ] رجوع اللاعب ← نفس الفريق ونفس الرقم
- [ ] «اطلع وابدأ من جديد» ثم «انضمام كلاعب» ← بحث جديد، مش رجوع للعبة القديمة
- [ ] المضيف يطلع من اللوح ← كل اللاعبين بيشوفوا الانقطاع فوراً
- [ ] قفل شاشة جهاز اللاعب وفتحها ما بيقطع الاتصال

## الشاشة

- [ ] بالعرضي على جهاز بنوتش: ما في شريط أسود، التايمر والأخطاء بالزاويتين والمحتوى مش مقصوص
- [ ] كل شاشة بالوضعين بدون تمرير (إلا إعدادات المضيف) وبدون نص مقصوص
- [ ] الواجهة كلها RTL والأرقام هندية عربية

## التوافق

- [ ] تكرار الاختبار على شركتين مصنّعتين مختلفتين (مثلاً Samsung وXiaomi) —
      بعض الأجهزة بترمي بثّ UDP لو ما في قفل multicast، وبعضها بيوقف الواي فاي بالخلفية
- [ ] على شبكة واي فاي فيها عزل أجهزة (فندق/جامعة) الغرفة ما بتبيّن — والحل نقطة اتصال

> أي مشكلة بتطلع بهاي القائمة تتسجّل كـ issue قبل النشر.
