# بنك الأسئلة — شكل ملف الاستيراد

الملف **JSON** واحد، ترميزه UTF-8، وبينستورد من: **الإعدادات ← بنك الأسئلة ← استيراد ملف**.

## الشكل

الجذر **مصفوفة** أسئلة:

```json
[
  {
    "id": "q001",
    "text": "اذكر شي بيعمله الناس أول ما يصحوا من النوم",
    "category": "عام",
    "isRead": false,
    "answers": [
      { "text": "يشيّكوا الموبايل", "points": 40 },
      { "text": "يشربوا قهوة", "points": 30 },
      { "text": "يغسلوا وجّهم", "points": 20 },
      { "text": "يصلّوا", "points": 10 }
    ]
  },
  {
    "text": "اذكر مكان بيروح عليه الناس بالعطلة",
    "answers": [
      { "text": "البحر", "points": 35 },
      { "text": "الجبل", "points": 25 },
      { "text": "بيت الأهل", "points": 20 },
      { "text": "برّا البلد", "points": 12 },
      { "text": "المولات", "points": 8 }
    ]
  }
]
```

## الحقول

| الحقل | لازم؟ | القاعدة |
|---|---|---|
| `text` (السؤال) | إي | نص مش فاضي |
| `answers` | إي | من **٢** لـ **٩** أجوبة (اللعبة بتفلتر لحد **٨**) |
| `answers[].text` | إي | نص مش فاضي |
| `answers[].points` | إي | رقم صحيح **أكبر من صفر** |
| `category` | لأ | نص؛ بينحفظ بس ما بينعرض ولا بينفلتر فيه |
| `id` | لأ | نص؛ إذا ما حطيته بينحسب `q1`، `q2`... |
| `isRead` | لأ | `true` يعني السؤال انقرأ وما بدك ياه يرجع (الافتراضي `false`) |

**تكرار الأسئلة**: التطبيق بيسجّل كل سؤال بيبيّن عند المضيف ككل «مقروء»،
وما بيرجع يستعمله لحد ما تخلص أسئلة البنك كلها — وبعدها بيبلّش دورة جديدة.
بتقدر تعلّم أسئلة كمقروءة من الملف نفسه بـ `"isRead": true`. استيراد بنك
جديد (أو حذف البنك) بيصفّي سجل القراءة.

**التصنيف** بينقرأ من الملف بس **ما بيبيّن باللعبة ولا بينفلتر فيه** — التصفية
صارت بعدد الأجوبة بس: بإعدادات المضيف بتحدّد أقل وأكثر عدد أجوبة، والعدّاد
بيقول كم سؤال بيطابق قبل ما تبلّش.

«أقل عدد أجوبة» و«أكثر عدد أجوبة» إعدادين مستقلّين، وحدودهم بتتبنى من الملف
نفسه — أصغر وأكبر عدد أجوبة موجود فعلياً بالبنك، وبأقصى حد **٨** (نفس عدد
خانات اللوح). الافتراضي: **أقل عدد أجوبة ٥**.

قواعد إضافية:

- الأجوبة بتنرتّب لحالها **من الأعلى نقاط للأقل** — ما بتفرق كيف كتبتها بالملف.
  الترتيب هو ترتيب اللوح، وجواب رقم ١ (الأعلى) هو اللي بياخد اللوح بالمواجهة.
- اللوح دايماً ٨ خانات؛ السؤال اللي أجوبته أقل بتضل خاناته الباقية فاضية.
- أي مفتاح زيادة بينتجاهل، فما بيضر لو أضفت حقول لحالك.
- لازم عدد الأسئلة بالملف ≥ عدد الجولات المضبوط بإعدادات المضيف (حتى ٨ جولات)،
  والأفضل يكون أكتر بكتير لأن كل لعبة بتسحب أسئلة عشوائية.
- أي غلط بالملف بيرجّع رسالة عربية بتقول رقم السؤال والمشكلة، والبنك القديم بيضل شغّال.

## نصيحة للنقاط

خلّي مجموع نقاط أجوبة السؤال الواحد قريب من **١٠٠** (زي البرنامج)، والأجوبة
مرتّبة منطقياً: الجواب المتوقّع أكتر بياخد أعلى رقم.

## برومبت جاهز لتوليد بنك بالذكاء الاصطناعي

انسخ هاد ولزّقه بأي نموذج (Claude، ChatGPT…) وبدّل الموضوع وعدد الأسئلة:

```
اكتبلي بنك أسئلة للعبة عربية على طراز Family Feud، بصيغة JSON فقط بدون أي شرح
قبله أو بعده، وبدون علامات ``` حواليه.

الشكل: مصفوفة أسئلة، كل سؤال فيه:
- "text": نص السؤال بالعامية السورية، ويبلّش بـ«اذكر...» أو «شو...»
- "answers": من 4 إلى 9 أجوبة، كل جواب فيه:
  - "text": جواب قصير (كلمة لكلمتين)
  - "points": رقم صحيح أكبر من صفر

شروط:
- مجموع نقاط أجوبة كل سؤال = 100 تقريباً
- الأجوبة مرتّبة من الأعلى نقاط للأقل
- الأجوبة لازم تكون إجابات يقولها ناس عاديين، مش أجوبة أكاديمية
- بدون تكرار بين الأسئلة
- كل النصوص عربية

اعطيني 40 سؤال.
```

بعدها احفظ الناتج بملف `.json` (ترميز UTF-8) وستوردو من الإعدادات.
البنك المرفق مع التطبيق فيه ٥٠ سؤال، وبتقدر ترجعله بأي وقت من زر «حذف».
