# أصوات اللعبة — كيف بتنبنى

كل ملفات `assets/sounds/sfx_*.mp3` مولّدة من هون، مش مسجّلة من أي برنامج:

- **`synth.js`** — عناصر مركّبة رقمياً ١٠٠٪ (هواء، بزّرات، صعود توتّر، أجراس، نفخة
  الفوز، تكّات الساعة، فرقعات).
- **`build.js`** — الوصفات: لكل تنبيه طبقات (عيّنات + عناصر مركّبة) بتوقيت وحجم
  ودرجة، بتتخلط وتتعالج بـffmpeg (مرشّحات، صدى)، وبتتعاير لنفس الحجم المسموع
  (‎-10 LUFS للأحداث الكبيرة، أهدى للنقرات) بمحدّد ‎-1 dBFS، وبتتصدّر MP3.

## العيّنات

من حزم [Kenney](https://kenney.nl) الصوتية — رخصة **CC0** (ملك عام: بدون شرط
نسب، وبتنستعمل تجارياً): Interface Sounds، UI Audio، Casino Audio، Impact
Sounds، Digital Audio. الحزم مش بالمستودع (حمّلها من الموقع وفكّها بمجلد).

## إعادة البناء

```bash
node tools/sfx/build.js <مجلد-الحزم> assets/sounds [مسار-ffmpeg]
```

`<مجلد-الحزم>` فيه `interface-sounds/Audio/…`، `impact-sounds/Audio/…` إلخ.
بيطبع جدول بالحجم المسموع قبل وبعد لكل صوت. بدّل وصفة بـ`build.js` وأعد
البناء — ما في شي يدوي.
